# Sirkula Jogja

Project Flutter dengan target Android.

## Menjalankan

1. Pasang Flutter SDK dan Android Studio, lalu pastikan `flutter` tersedia di `PATH`.
2. Jalankan `flutter doctor` untuk memeriksa toolchain Android.
3. Dari folder project, jalankan:

   ```powershell
   flutter pub get
   flutter run
   ```

Kode aplikasi berada di `lib/`. Konfigurasi dan project native Android berada di `android/`.
